How this works. Every folder in the repo that doesn't start with _ is a student. The roster above is read live from GitHub, so adding a student folder is all it takes. To add misses after a session, open the student's seed.js on GitHub, paste the new entry at the top of the array (use New seed entry to generate it), and commit. The student refreshes and sees it; their own logged misses and mastery are untouched. Rules: never reuse a seed id, and never rename a student folder once the link has been sent.
